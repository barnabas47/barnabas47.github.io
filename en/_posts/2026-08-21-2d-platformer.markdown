description: |
  [ORIGAMI VOID — Speedrun Edition](https://github.com/barnabas47/2d_platformer) is a dimension-folding 2D speedrun puzzle-platformer built completely with pure HTML5 Canvas & Web Audio API. Playable live in browser at [https://barnabas47.github.io/2d_platformer/](https://barnabas47.github.io/2d_platformer/).

  **Main features:**
  - **Dimension Folding & Relative Gravity**: Spatial gravity vector manipulation — attach to vertical 90° walls and ceiling undersides with dynamic relative movement controls.
  - **Millisecond Speedrun Engine (`00:00.000`)**: High-precision timer tracking with saved Personal Best records stored in `localStorage`.
  - **3-Second Crumbling Platforms**: Timed yellow platforms dissolve 3 seconds after touch with ember particles and a top progress bar.
  - **360° Rotating Radar Lasers**: Dodge slowly sweeping red radar beam hazards across 2D space.
  - **Dynamic Laser Shadow Blocking**: Solid level platforms and spawner Fold Platforms dynamically block vertical laser beams, casting safe shadows underneath.
  - **Synthesized Web Audio Engine**: Built-in Web Audio API sound synthesizer with interactive volume sliders in both Main Menu and HUD header.
  - **100% Fullscreen Viewport Scaling**: Seamlessly scales to fill 100% of any browser viewport (`100vw` × `100vh`) with zero layout jittering (`tabular-nums`).

  **Technologies:**
  - Rendering: HTML5 Canvas 2D Context (motion trails & particle FX)
  - Logic: Vanilla JavaScript ES6+ (zero external dependencies)
  - Audio: Web Audio API (procedural sound synthesis)
  - Styling: CSS3 Neofuturistic Cyberpunk styling & glassmorphism UI overlay

  **How to run:**
  - Open `index.html` in any modern web browser or visit the live playable game at [https://barnabas47.github.io/2d_platformer/](https://barnabas47.github.io/2d_platformer/).
