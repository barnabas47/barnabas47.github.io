description: |
  [OmniClaim-AI](https://github.com/barnabas47/OmniClaim-AI) is an autonomous flight passenger rights advocate & weather bluff disprover multi-agent platform submitted to the **AWS Agents for Humans Hackathon** built with **Strands Agents SDK** and **AWS Bedrock AgentCore**.

  **Main features:**
  - **Multimodal Vision OCR Document Ingestion**: Automated extraction of boarding passes, flight tickets, and hotel/meal expense receipts from photos/PDFs.
  - **Airline Weather Bluff Disprover**: Real-time fetching of official airport METAR meteorological observations and parallel flight departure rates to empirically disprove false "force majeure" claims by airlines.
  - **Great-Circle Geodesic Distance Math**: Geodesic flight distance calculation mapping statutory legal compensation entitlements (€250 / €400 / €600 under EU261/UK261/US DOT rules) + out-of-pocket Duty of Care expense reimbursements.
  - **Pre-Filled Carrier Claim Packages**: Auto-generation of official airline claim forms (Lufthansa, Ryanair, WizzAir, etc.) and formal legal demand letters.
  - **1-Click Human-in-the-Loop (HITL) Gate**: Surfaces clean decision cards for 1-click passenger authorization.
  - **Native Android Mobile App**: 100% Native Java Android mobile application + FastAPI REST API backend.

  **Technologies:**
  - AI & Multi-Agent: Strands Agents SDK (`strands-agents`), AWS Bedrock AgentCore (Claude 3.7 Sonnet / Nova)
  - Backend: Python (FastAPI), Vision OCR, METAR weather parser, Great-Circle math
  - Frontend & Mobile: React (Vite, TypeScript, Tailwind CSS), Native Android (Java)

  **How to run:**
  - Open the project directory and run the 1-click launcher: `START_OMNICLAIM.bat` (browser: `http://localhost:3000`)
