description: |
  [Cosmic Trade-off](https://github.com/barnabas47/Cosmic-Trade-off) egy interaktív, 0-scroll 100vh mélyűri küldetéstervező laboratórium és valós idejű repülésirányító kokpit, amely a NASA International Space Apps Challenge versenyre készült. A rendszer az asztrodinamikát és a mérnöki kompromisszumos döntéshozatalt ötvözi.

  **🚀 Főbb funkciók:**
  - **Keplerian 2-Body Orbital Solver**: Heliocentrikus kúpkúp-pálya terjedési szimuláció Hohmann-pályákkal és Oberth-hatású gravitációs hintamanőverekkel.
  - **Tsiolkovsky Rakéta Mátrix**: Nedves/száraz tömegarány számítás, fajlagos impulzus ($I_{sp}$) mérlegelések és $\Delta v$ költségvetési tartalék ellenőrzés.
  - **HTML5 2.5D/3D Canvas Engine**: Folyamatos 360°-os szférikus kameramozgás, bolygópályák és részecske-alapú RCS/fúvóka hajtóműcsóvák.
  - **Web Audio Synth**: Eljárásilag szintetizált Apollo/Artemis Quindar sípszók, kriogén gyújtási robaj, hideggáz kiáramlások és küldetésirányítási C-dúr fanfár.
  - **5 Interaktív Repülésirányítói Minijáték**: RCS dokkolás, hőszigetelő pajzs beállítás, napelemes panel irányzék, pályára állás és jeldekódolás.

  **🛠️ Fő technológiák:**
  - Frontend: React 18, TypeScript 5.7, Vite 6, Tailwind CSS
  - Design System: Google Stitch + 21st.dev Dark Telemetry UI (Pure 100vh Single-Screen)
  - Physics & Audio: Keplerian Orbit Solver, Tsiolkovsky Rocket Equation, Web Audio API Synth

  **🏁 Indítás:**
  - Klónozd a tárolót: `git clone https://github.com/barnabas47/Cosmic-Trade-off.git`
  - Telepítsd a függőségeket: `npm install`
  - Indítsd el a fejlesztői szervert: `npm run dev`
